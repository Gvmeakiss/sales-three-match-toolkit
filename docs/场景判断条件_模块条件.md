# 三单匹配场景判断条件

> 本文档按场景标号梳理「订单」「交货单」「发票」在数量、金额维度上的判断条件，用于各模块分类与交叉汇总。

## 一、判断结构说明

| 维度 | 结构 | 说明 |
|------|------|------|
| **数量判断** | (订单数量 [op] 交货单数量) **且** (订单数量 [op] 发票数量) | 两个比较条件均需满足；op ∈ {=, >, <} |
| **金额判断** | 订单金额 [op] 发票金额 | 直接比较；op ∈ {=, >, <} |

**容差**：数值比较默认使用 0.01 作为相等判定容差（如 `|a-b| < 0.01` 视为 a=b）。

## 四、布尔判定伪代码

```python
# 数量判断（容差 TOL=0.01）
ord_vs_dlv_eq = abs(订单数量 - 交货数量) < TOL
ord_vs_dlv_gt = 订单数量 > 交货数量 + TOL
ord_vs_dlv_lt = 订单数量 < 交货数量 - TOL

ord_vs_inv_eq = abs(订单数量 - 发票数量) < TOL
ord_vs_inv_gt = 订单数量 > 发票数量 + TOL
ord_vs_inv_lt = 订单数量 < 发票数量 - TOL

# 金额判断
amt_eq = abs(订单金额 - 发票金额) < TOL
amt_lt = 订单金额 < 发票金额 - TOL
amt_gt = 订单金额 > 发票金额 + TOL
```
