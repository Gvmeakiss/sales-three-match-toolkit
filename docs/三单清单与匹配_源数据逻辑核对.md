# 三单清单与三单匹配 源数据逻辑核对

## 一、数据源对比

| 数据 | three_lists | sales_three_match |
|------|-------------|-------------------|
| **订单** | VBAK + VBAP | VBAK + VBAP |
| **交货** | LIKP + LIPS | LIKP + LIPS |
| **发票** | VBRK + VBRP | VBRK + VBRP |

两者使用相同的 TXT 源文件，通过 `DATA_FOLDER` / `SALES_DATA_FOLDER` 指向公司目录（如 `InPut/4110`）。

### 4. 计算与合并逻辑

| 维度 | three_lists | sales_three_match | 一致？ |
|------|-------------|-------------------|--------|
| **SHKZG 符号** | S/H/X 映射（仅用于交货、发票） | 同 | ✓ |
| **订单金额** | NETWR×WKURS（不做 SHKZG 取负） | 同 | ✓ |
| **订单数量** | KLMENG 或 KWMENG×UMVKZ/UMVKN（不做 SHKZG 取负） | 同 | ✓ |
| **交货数量** | LFIMG×shkzg_map | 同 | ✓ |
| **发票金额** | NETWR×shkzg_map | 同 | ✓ |
| **发票数量** | FKIMG×shkzg_map | 同 | ✓ |
| **合并键** | VKORG, VBELN, POSNR | 同 | ✓ |

**说明**：订单金额与数量不再按 SHKZG/RETPO 取负，仅用原始数值。详见 `docs/订单金额正负判断条件_核对.md`。
