# 差异分析分类逻辑审阅

## 一、四大类分类逻辑

| 大类 | 判定条件 | 差异描述 |
|------|----------|----------|
| **无差异** | \|订单-发票金额差异\| < 0.01 且 \|订单-发票数量差异\| < 0.01 | 订单与发票在金额、数量上均一致 |
| **金额差异** | 非无差异，且 \|金额差异\| ≥ 0.01、\|数量差异\| < 0.01 | 金额有差异，数量一致 |
| **数量差异** | 非无差异、非金额差异，且 \|数量差异\| ≥ 0.01、\|金额差异\| < 0.01 | 数量有差异，金额一致 |
| **均有差异** | 非前三类，且 \|金额差异\| ≥ 0.01、\|数量差异\| ≥ 0.01 | 金额、数量均有差异 |

**一致性**：✓ 逻辑互斥且完备，与 summarize 的「无差异」定义一致（容差 0.01）。

## 二、金额差异细分

| 子类 | 判定条件 | 差异描述 |
|------|----------|----------|
| **尾差(<1)** | 金额差异 且 \|订单-发票金额差异\| < 1 | 金额差异在 1 元以内，多为四舍五入 |
| **汇率导致尾差** | （占位，暂无） | 暂无汇率字段 |
| **交货成本导致差异** | （占位，暂无） | 销售场景无交货成本字段 |
| **金额差异—其他** | 金额差异 且非上述子类 | 其他金额差异（\|差异\| ≥ 1） |

**一致性**：✓ 尾差与其他边界清晰。

## 三、均有差异细分（需修正）

| 子类 | 判定条件 | 差异描述 | 当前实现 |
|------|----------|----------|----------|
| **未完全交货** | 订单>交货 且 交货≈发票 | 部分交货，已交部分已全部开票 | ✓ 一致 |
| **过量交货** | 订单<交货 且 交货≈发票 | 超量交货，已按交货量开票 | ✓ 一致 |

| **预制发票** | 订单>交货 且 发票>交货 且 订单≈发票 | 未完全交货但已按订单全额开票 | ✓ 一致 |
| **均有差异—其他** | 均有差异且未落入以上子类 | 其他金额+数量双差异场景 | ✓ 一致 |

### 问题：未完全开票逻辑反了

- **语义**：未完全开票 = 已交货但尚未全部开票 → **交货数量 > 发票数量**
- **当前代码**：`df[dlv_col] < df[inv_col]` → 交货<发票 → 表示**超额开票**，与语义相反
- **修正**：应为 `df[dlv_col] > df[inv_col]` → 交货>发票
